## Server (`demo/server.ts`)

- `import * as jscaw from '../index.js'`, `import { watchApp } from '../magic.mjs'`, `import index from './index.html'`.
- `export function startDemo(port = 3000)` returns the `Bun.serve({ hostname: '127.0.0.1', port, routes: { '/': index }, fetch: upgrade on /ws, websocket })` server; `if (import.meta.main)` starts it and prints `http://localhost:<port>`.
- **RPC** — client sends `{ id, fn, args }`, gets `{ id, result }` or `{ id, error }`.
  - Allow-list = jscaw exports that are functions and don't start with `on` (so every getter/setter, generated from the module, no hand list to drift), plus demo-local fns:
    - `watchApp(exe)` → magic id; `magic(id, op, value?)` with op ∈ `volume|mute|toggleMute|stepVolume|dispose`
    - `watchEndpoint(deviceId?)` → swaps the single `onEndpointVolumeChange` subscription
  - `fn` not in allow-list → `{ id, error: 'unknown fn: X' }`. Errors thrown by jscaw are returned as `error: e.message`.
- **Events** — all go through `server.publish('events', JSON.stringify({ type, event }))`:
  - at start: `onDeviceEvent`, `onSessionCreated`, `onDuckEvent`, `onEndpointVolumeChange` (default device).
  - `onSessionEvent({ instanceId })` per session, tracked in a `Map<instanceId, unsubscribe>` seeded from `listSessions({ includeSystemSounds: true })` and grown by `onSessionCreated`; dropped on `expired`/`disconnected` (same pattern as `magic.mjs`).
  - magic callbacks (`onVolume/onMute/onState/onSessionsChanged`) published as `{ type: 'magic', id, kind, value }`.
  - `null` returns (no device, CI) are skipped — empty states, no errors.
- **Meters** — `setInterval` at 50 ms, only when `server.subscriberCount('events') > 0`: publishes `{ type: 'meters', endpoint: getEndpointPeak(), sessions: { [instanceId]: getSessionPeak({ instanceId })[0] } }`.
- **Shutdown** — `stopDemo()` unsubscribes everything, disposes magic watchers, clears the interval, `server.stop()`. SIGINT calls it. The test calls it too.

## Client (`demo/index.html` + `demo/app.ts`)

`call(fn, ...args)` returns a promise keyed by id. One `<section>` per panel, each with a `<pre>` showing the equivalent jscaw snippet:

- **Devices** — render/capture lists with state filter (`listDevices`), default markers per role (`getDefaultDevice` × roles), "Make default" (`setDefaultDevice`), `<details>` property table (`getDeviceProperties`, loaded on open). Re-render on any `device` event.
- **Endpoint volume** — device select, master slider, dB input (min/max from `range`), mute, per-channel sliders, step up/down, peak bar. Refresh on `endpointVolume` events; mark "external" when `!selfInitiated`.
- **Sessions mixer** — row per session: volume/mute, per-channel sliders (`getSessionChannelVolumes`), peak bar, state, editable display name / icon path / grouping (on `change`), ducking opt-out checkbox, include-system-sounds toggle. Rows re-list on `sessionCreated` / session events.
- **Duck log**, **Magic** (exe input → `watchApp`, aggregated volume/mute, toggle/step/dispose, callback log), **Event log** (every message, timestamped, capped at ~200 lines).

Native platform only: `<input type=range>`, `<details>`, `<progress>`/`<meter>` for peaks, no framework.

## Tests (`demo/server.test.ts`, written first)

`startDemo(0)`; then
1. `GET /` → 200, `content-type` includes `text/html`
2. WS `{ id: 1, fn: 'listDevices' }` → `result` is an array
3. WS `{ id: 2, fn: 'eval' }` → has `error`
4. WS `{ id: 3, fn: 'onDeviceEvent' }` → has `error` (subscriptions not callable via RPC)

`afterAll(stopDemo)`. Must pass on CI with no audio devices.

**Gotcha:** Node 24 (local v24.20, CI) strips types by default, so plain `node --test` would also pick up `demo/server.test.ts` and fail on `Bun`. Pin the `test` script to `__test__/*.test.mjs`. `bun test` (CI's bun job) picks the demo test up automatically.
